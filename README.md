# ShortsMaker

İngiliscə ssenaridən avtomatik YouTube videosu (Shorts 1080×1920, maks. 59 san, və ya uzun video 1920×1080) hazırlayan Windows proqramı: səsləndirmə, stok video və subtitr.

## Yükləmə
**Releases** bölməsindən ən son `ShortsMaker.exe` faylını yükləyin və iki dəfə klikləyin. Heç nə quraşdırmaq lazım deyil.

## İstifadə
1. Pulsuz Pixabay açarı alın: pixabay.com saytında qeydiyyatdan keçin, sonra https://pixabay.com/api/docs/ səhifəsində açarınız göstərilir (bir dəfə).
2. Açarı proqramdakı xanaya yapışdırın. Açar yadda qalır.
3. Ssenarini yazın. Hər abzas bir səhnədir.
   Videonu özünüz seçmək üçün abzasın əvvəlinə `[açar söz]` yazın.
4. **Video yarat** düyməsini basın. Hazır video `Videos\ShortsMaker` qovluğuna yazılır.
